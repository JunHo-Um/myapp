# 업비트 자동매매 봇

업비트 API를 사용한 자동매매 프로그램입니다. 다양한 거래 전략을 지원하며, 실시간으로 시장 상황을 모니터링하여 자동으로 매매를 실행합니다.

## 주요 기능

- **실시간 시장 모니터링**: 업비트 API를 통해 실시간 가격 정보 수집
- **다양한 거래 전략**: 이동평균 크로스오버, 볼린저 밴드 등
- **자동 매매 실행**: 설정된 전략에 따라 자동으로 매수/매도 주문
- **계좌 관리**: 잔고 조회, 주문 상태 확인
- **로깅 시스템**: 상세한 거래 로그 기록
- **사용자 인터페이스**: 콘솔 기반의 직관적인 메뉴 시스템

## 지원하는 거래 전략

### 1. 이동평균 크로스오버 전략
- 단기/장기 이동평균선의 교차를 이용한 매매
- 가격 변화율 기반 매수/매도 신호 생성
- 설정 가능한 임계값과 투자 비율

### 2. 볼린저 밴드 전략
- 볼린저 밴드의 상단/하단 터치를 이용한 매매
- 표준편차 기반 매매 신호 생성
- 변동성 활용 전략

## 설치 및 실행

### 1. 사전 요구사항
- Java 11 이상
- Maven 3.6 이상
- 업비트 API 키 (액세스 키, 시크릿 키)

### 2. 업비트 API 키 발급
1. [업비트](https://upbit.com) 계정으로 로그인
2. 마이페이지 → Open API 관리
3. API 키 생성 (주문하기, 주문 조회, 잔고 조회 권한 필요)
4. 발급받은 액세스 키와 시크릿 키를 안전하게 보관

### 3. 프로젝트 빌드
```bash
# 프로젝트 클론
git clone <repository-url>
cd upbit-trading-bot

# Maven으로 빌드
mvn clean package
```

### 4. 설정 파일 수정
`config.yaml` 파일을 열어 API 키를 설정합니다:

```yaml
api:
  access_key: "YOUR_ACCESS_KEY_HERE"  # 실제 액세스 키로 변경
  secret_key: "YOUR_SECRET_KEY_HERE"  # 실제 시크릿 키로 변경
```

### 5. 프로그램 실행
```bash
# JAR 파일 실행
java -jar target/upbit-trading-bot-1.0.0.jar
```

## 사용법

프로그램 실행 후 다음과 같은 메뉴가 표시됩니다:

```
=== 업비트 자동매매 봇 ===
1. 자동매매 시작
2. 자동매매 중지
3. 계좌 정보 조회
4. 현재가 조회
5. 종료
========================
```

### 메뉴 설명

1. **자동매매 시작**: 설정된 전략에 따라 자동매매를 시작합니다
2. **자동매매 중지**: 실행 중인 자동매매를 중지합니다
3. **계좌 정보 조회**: 현재 보유한 자산 정보를 확인합니다
4. **현재가 조회**: 설정된 마켓의 현재가 정보를 확인합니다
5. **종료**: 프로그램을 종료합니다

## 설정 옵션

`config.yaml` 파일에서 다양한 설정을 변경할 수 있습니다:

### 거래 설정
- `market`: 거래할 마켓 (예: KRW-BTC, KRW-ETH)
- `check_interval`: 가격 체크 간격 (초)
- `min_krw_balance`: 최소 KRW 잔고 (원)

### 전략 설정
- `strategy.type`: 사용할 전략 타입
- `buy_threshold`: 매수 임계값
- `sell_threshold`: 매도 임계값
- `max_investment_ratio`: 최대 투자 비율

## 주의사항

⚠️ **중요한 주의사항**

1. **실제 자금 거래**: 이 프로그램은 실제 자금으로 거래를 실행합니다
2. **리스크 관리**: 투자 금액을 신중하게 설정하고, 손실 가능성을 고려하세요
3. **API 키 보안**: API 키를 안전하게 보관하고, 타인과 공유하지 마세요
4. **시장 변동성**: 암호화폐 시장은 매우 변동성이 크므로 주의가 필요합니다
5. **테스트**: 실제 거래 전에 충분한 테스트를 진행하세요
