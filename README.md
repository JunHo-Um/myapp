# 업비트 자동매매 봇

업비트 API를 사용한 자동매매 프로그램입니다.

## 주요 기능

- 실시간 가격 모니터링
- 자동 매수/매도 전략 실행
- 수익 목표 및 손절 설정
- 안전한 API 인증 (JWT)
- 상세한 로깅

## 전략 설명

### 매수 조건
- 충분한 KRW 잔고가 있을 때
- 이전 매수 가격보다 2% 이상 하락했을 때 (또는 첫 매수)

### 매도 조건
- 수익 목표 달성 시 (예: 5% 수익)
- 손절 조건 달성 시 (예: 2% 손실)

## 설치 및 실행

### 1. 필수 요구사항
- Java 11 이상
- Maven 3.6 이상
- 업비트 API 키 (Access Key, Secret Key)

### 2. 업비트 API 키 발급
1. [업비트](https://upbit.com) 로그인
2. 마이페이지 → Open API 관리
3. API 키 발급 (주문하기, 주문 조회 권한 필요)

### 3. 환경변수 설정
```bash
export UPBIT_ACCESS_KEY=your_access_key_here
export UPBIT_SECRET_KEY=your_secret_key_here
```

### 4. 프로젝트 빌드
```bash
mvn clean package
```

### 5. 실행
```bash
java -jar target/upbit-trading-bot-1.0.0.jar
```

## 설정 예시

프로그램 실행 시 다음과 같은 설정을 입력합니다:

```
거래할 마켓을 입력하세요 (예: KRW-BTC): KRW-BTC
매수 금액을 입력하세요 (원): 100000
매도 비율을 입력하세요 (0.1 = 10%): 0.5
수익 목표를 입력하세요 (0.05 = 5%): 0.05
손절 비율을 입력하세요 (0.02 = 2%): 0.02
전략 실행 간격을 입력하세요 (초): 60
```

### 설정 설명
- **거래 마켓**: 거래할 코인 마켓 (예: KRW-BTC, KRW-ETH)
- **매수 금액**: 한 번에 매수할 금액 (원)
- **매도 비율**: 보유 코인의 몇 %를 매도할지 (0.5 = 50%)
- **수익 목표**: 목표 수익률 (0.05 = 5%)
- **손절 비율**: 손절할 수익률 (0.02 = 2%)
- **실행 간격**: 전략을 실행할 간격 (초)

## 주의사항

⚠️ **투자 위험 고지**
- 이 프로그램은 교육 목적으로 제작되었습니다
- 실제 투자에 사용할 경우 발생하는 손실에 대해 책임지지 않습니다
- 충분한 테스트 후 소액으로 시작하시기 바랍니다
