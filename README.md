# 스프링부트 대시보드 웹 애플리케이션

Bootstrap과 Thymeleaf를 사용한 스프링부트 기반의 대시보드형 테이블 구조 웹 UI입니다.

## 🚀 주요 기능

- **대시보드 개요**: 주요 통계 정보와 최근 데이터를 한눈에 확인
- **사용자 관리**: 사용자 정보 조회, 부서별/상태별 필터링
- **주문 관리**: 주문 현황 조회, 상태별 관리
- **제품 관리**: 제품 정보 관리, 재고 상태 모니터링

## 🛠 기술 스택

- **Backend**: Spring Boot 3.2.0, JPA/Hibernate
- **Database**: H2 Database (In-Memory)
- **Frontend**: Thymeleaf, Bootstrap 5.3, Font Awesome
- **Build Tool**: Maven

## 📋 테이블 구조

### 사용자 (User)
- ID, 이름, 이메일, 부서, 상태, 생성일

### 주문 (Order)
- 주문번호, 고객명, 제품명, 수량, 금액, 상태, 주문일

### 제품 (Product)
- 제품명, 카테고리, 가격, 재고, 상태, 설명

## 🚀 실행 방법

### 1. 프로젝트 클론 및 빌드
```bash
# 의존성 설치 및 빌드
mvn clean compile
```

### 2. 애플리케이션 실행
```bash
mvn spring-boot:run
```

### 3. 브라우저에서 접속
```
http://localhost:8080
```

## 📊 주요 화면

### 1. 대시보드 (/)
- 전체 통계 요약 카드
- 최근 등록된 사용자 테이블
- 최근 주문 목록
- 재고 부족 제품 알림

### 2. 사용자 관리 (/users)
- 전체 사용자 목록
- 부서별/상태별 필터링
- 검색 기능

### 3. 주문 관리 (/orders)
- 전체 주문 목록
- 상태별 필터링
- 날짜 범위 검색

### 4. 제품 관리 (/products)
- 전체 제품 목록
- 카테고리별/상태별 필터링
- 재고 상태 모니터링

## 🎨 UI 특징

- **반응형 디자인**: 모바일/태블릿/데스크톱 지원
- **Bootstrap 5**: 모던하고 깔끔한 디자인
- **Font Awesome**: 직관적인 아이콘 사용
- **상태별 색상 코딩**: 시각적으로 구분되는 배지와 버튼
- **테이블 정렬/필터링**: 사용자 친화적인 데이터 관리
